(Analysis) - New 'Analysis' Tab / future dashboard (this is a very big project)
    - Add a new top-level 'Analysis' button/tab next to 'Portfolio'.
    - This should be a whole new section, the same way that 'Portfolio' is its own tab.
    - First step is to do this analysis at the company level, store those results, and only after that aggregate them at the portfolio level.
    - The company-level analysis should also be available on demand when clicking into a company.
        - Right now the company view is mostly about the 'past'. There should be another tab which is about the 'future'.
        - This should be a highly advanced dashboard for that specific company.
        - It should focus on 2 main things:
            - how the fundamentals are expected to evolve, relative to peers in the sector and/or the S&P 500.
            - what news have moved the company, and from those news what are the main momentum drivers behind the excess returns / idiosyncratic component.
    - The analysis should collect and combine:
        - analyst expectations / revisions.
        - forward-looking fundamentals and estimates.
        - news sentiment and the main themes / topics trending for the company.
        - the biggest news in the recent months and how much the stock moved after them.
        - peer / sector / market comparison so the company is judged in relative terms, not only in isolation.
    - This should then produce a smart dashboard which shows how 'strong' each candidate is.
        - Similar idea to the analyst tab, but much more complete.
        - It should clearly show whether the strength is coming from news momentum, future fundamentals growth, revisions up, or some combination of those.
    - After doing this for each company, aggregate everything at the portfolio level.
        - When clicking 'Analysis', the user should get a very strong summary dashboard for all the companies in the portfolio.
        - The goal is to identify the companies which have the strongest news momentum and/or future fundamentals growth potential.
        - Then use that to make judgements on whether to remove, overweight, or underweight positions.
    - Need to think carefully about storage / caching.
        - Per-company analysis should be saved locally so it does not need to be recomputed every time.
        - Portfolio analysis should be built on top of those stored company-level results.
